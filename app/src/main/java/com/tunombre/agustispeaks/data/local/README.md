# data/local

Fuentes de datos locales.

- **Room**: `AppDatabase`, entidades (`PictogramEntity`, `FavoriteEntity`,
  `PhraseHistoryEntity`), DAOs y `TypeConverters` para las listas
  (`placeIds`, `categoryIds`).
- **DataStore (Preferences)**: `SettingsDataStore` para persistir
  `UserSettings` (tono y velocidad de voz, tamaño de texto, alto contraste,
  columnas de grilla).
