# data/repository

Repositorios que combinan los datos semilla (lugares, categorías y
pictogramas por defecto) con lo almacenado en Room y DataStore, y exponen
el resultado como flujos a los ViewModel.

Previsto:
- `BoardRepository` — lugares, categorías y pictogramas filtrados por lugar.
- `FavoritesRepository` — favoritos e historial de frases.
- `SettingsRepository` — lectura/escritura de `UserSettings`.

Pendiente de implementar.
